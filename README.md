# 🌟 Portfolio - Saloua Bourmada | معرض الأعمال والحلول الذكية

مرحباً بك في المستودع الرسمي لمعرض أعمال المهندسة **Saloua Bourmada** (مهندسة برمجيات وتطوير ويب). يحتوي هذا الموقع على عرض متكامل للمشاريع البرمجية، المنصات التعليمية، وأدوات الذكاء الاصطناعي الحديثة.

---

## 📂 هيكل الملفات والمشروع (Project Structure)

```text
my-portfolio-main/
│
├── index.html                  # الصفحة الرئيسية لمعرض الأعمال (عربي)
├── index-en.html               # الصفحة الرئيسية لمعرض الأعمال (English)
├── styles.css                  # التنسيقات العامة والتأثيرات البصرية والـ Mockups
├── ai-tools.html               # الصفحة المباشرة لمنصة عالم أدوات الذكاء الاصطناعي
│
├── ai-tools/                   # مجلد منصة أدوات الذكاء الاصطناعي المتكاملة
│   ├── index.html              # واجهة منصة الأدوات
│   ├── guide-pdf.html          # الدليل الشامل المخصص للطباعة كـ PDF
│   ├── css/style.css           # تنسيقات الزجاج المائي والألوان الفيروزية
│   ├── js/data.js              # قاعدة بيانات 23+ أداة ذكاء اصطناعي
│   ├── js/app.js               # المحرك والبحث والفلترة والمفضلة
│   └── assets/                 # صور وهوية المنصة
│
├── posters/ (الملصقات الإشهارية والتعريفية بالمشاريع)
│   ├── poster-ai-tools.html    # ملصق عالم أدوات الذكاء الاصطناعي (AR)
│   ├── poster-ai-tools-en.html # ملصق عالم أدوات الذكاء الاصطناعي (EN)
│   ├── poster-budget.html      # ملصق نظام ميزانية التسيير
│   ├── poster-summarizer.html  # ملصق CourseCraft AI
│   ├── poster-smart.html       # ملصق BASMA SMART
│   ├── poster-moodle.html      # ملصق نظام حسابات Moodle
│   ├── poster-school.html      # ملصق نظام مدرستي
│   ├── poster-animals.html     # ملصق قصص الحيوانات التفاعلية
│   └── poster-lang.html        # ملصق منصة تعلم الإنجليزية والفرنسية
│
└── assets/ (الصور والوسائط والشعارات)
    ├── avatar.png
    ├── budget-logo.svg
    ├── coursecraft-ai.jpg
    ├── school-logo.svg
    └── ...
```
